## Запуск

Требуется JDK 21. В IntelliJ: открыть проект, выбрать JDK, отметить src как Sources Root. Каждая часть запускается своим main. Рабочая папка — корень этого проекта.

Из PowerShell:

```powershell
$sourceFiles = @(Get-ChildItem src -Recurse -Filter *.java | ForEach-Object FullName)
javac -encoding UTF-8 -d build @sourceFiles
java -cp build part1_methods.Main
java -cp build part2_decomposition.Main
java -cp build part3_calculator.Main
```

## Что показать на защите

Сначала методы с разными аргументами и возвращаемыми типами, затем диалог из маленьких методов. В калькуляторе покажи продолжение с предыдущим результатом и деление на ноль.

## Как объяснить

Метод выделяет одну задачу, получает параметры и может вернуть результат через return. void означает отсутствие возвращаемого значения. main управляет последовательностью, а детали вынесены в методы ввода, вывода, рекомендации и подтверждения повтора. Псевдокод находится в комментарии над Main.

## Возможные вопросы

- **Параметр и аргумент — одно и то же?** Параметр объявляется в методе; аргумент — фактическое значение при вызове.
- **Зачем декомпозиция?** Чтобы части можно было понимать, проверять и менять независимо.
- **Как обработано деление на ноль?** Метод divide выбрасывает исключение; диалог выводит сообщение и продолжает работу.
